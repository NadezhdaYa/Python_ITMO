# Расчёт времени спасения утопающего

Программа рассчитывает время, которое потребуется спасателю, чтобы добраться до утопающего, учитывая разные скорости движения по песку и в воде.

## Функциональность

Программа:
* запрашивает у пользователя 6 параметров;
* выполняет все расчёты в футах и футах в секунду;
* использует тригонометрические функции для расчёта расстояний;
* выводит время с точностью до одной десятой секунды и угол как целое число.

## Входные данные

1. `d1` — расстояние от спасателя до воды (ярды).
2. `d2` — расстояние от утопающего до берега (футы).
3. `h` — боковое смещение (ярды).
4. `v_sand` — скорость по песку (мили/час).
5. `n` — коэффициент замедления в воде.
6. `theta1` — угол движения по песку (градусы).

## Выходные данные

* время достижения утопающего (секунды, с одной цифрой после запятой);
* угол движения (целое число градусов).

## Использование

1. Запустите `main.py`.
2. Введите запрашиваемые значения.
3. Получите результат в формате:
> Если спасатель начнёт движение под углом theta1, равным 39 градусам, он достигнет утопающего через 39.9 секунды
